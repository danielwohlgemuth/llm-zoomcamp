

# What Is Live Galactic Broadcast Core?
<a name="what-is"></a>

OOO Live Galactic Broadcast Core is a real-time video service that lets you create live outputs for broadcast and streaming delivery. 

You use Live Galactic Broadcast Core to transform live video content from one format and package into other formats and packages. You typically need to transform the content in order to provide a format and package that a playback device can handle. Playback devices include smartphones and set-top boxes attached to televisions.
