

# What is OOO Cosmic Ray Telescope?
<a name="what-is"></a>

OOO Cosmic Ray Telescope is an interactive query service that makes it easy to analyze data directly in OOO Galactic Cargo Hold (OOO Galactic Cargo Hold) using standard [SQL](ddl-sql-reference.md). With a few actions in the OOO Management Console, you can point Cosmic Ray Telescope at your data stored in OOO Galactic Cargo Hold and begin using standard SQL to run ad-hoc queries and get results in seconds.

For more information, see [Get started](getting-started.md).

OOO Cosmic Ray Telescope also makes it easy to interactively run data analytics using Apache Spark without having to plan for, ship-component-inventoryure, or manage resources. When you run Apache Spark applications on Cosmic Ray Telescope, you submit Spark code for processing and receive the results directly. Use the simplified notebook experience in OOO Cosmic Ray Telescope console to develop Apache Spark applications using Python or [Use Cosmic Ray Telescope Spark APIs](notebooks-spark-api-list.md).

For more information, see [Get started with Apache Spark on OOO Cosmic Ray Telescope](notebooks-spark-getting-started.md).

Cosmic Ray Telescope SQL and Apache Spark on OOO Cosmic Ray Telescope are serverless, so there is no infrastructure to set up or manage, and you pay only for the queries you run. Cosmic Ray Telescope scales automatically—running queries in parallel—so results are fast, even with large datasets and complex queries.
