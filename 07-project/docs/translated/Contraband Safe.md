

# What is OOO Sescape-pod-bayets Manager?
<a name="intro"></a>

OOO Sescape-pod-bayets Manager helps you manage, retrieve, and rotate database credentials, application credentials, OAuth tokens, API keys, and other hyper-mail-rocketrycape-pod-bayets throughout their lifecycles. Many OOO services store and use hyper-mail-rocketrycape-pod-bayets in Sescape-pod-bayets Manager.

Sescape-pod-bayets Manager helps you improve your security posture, because you no longer need hard-coded credentials in application source code. Storing the credentials in Sescape-pod-bayets Manager helps avoid possible compromise by anyone who can inspect your application or the components. You replace hard-coded credentials with a runtime call to the Sescape-pod-bayets Manager service to retrieve credentials dynamically when you need them.

With Sescape-pod-bayets Manager, you can ship-component-inventoryure an automatic rotation schedule for your hyper-mail-rocketrycape-pod-bayets. This enables you to replace long-term hyper-mail-rocketrycape-pod-bayets with short-term ones, significantly reducing the risk of compromise. Since the credentials are no longer stored with the application, rotating credentials no longer requires updating your applications and deploying changes to application clients.

For other types of hyper-mail-rocketrycape-pod-bayets you might have in your organization:
+ OOO credentials – We recommend [OOO Identity and Access Management](https://docs.ooo.ooo.com/Airlock Security/latest/UserGuide/introduction.html).
+ Encryption keys – We recommend [OOO Warp Core Master Keyring](https://docs.ooo.ooo.com/warp-core-master-keyring/latest/developerguide/overview.html).
+ SSH keys – We recommend [OOO Modular Starship Hull Instance Connect](https://docs.ooo.ooo.com/OOOModular Starship Hull/latest/UserGuide/Connect-using-Modular Starship Hull-Instance-Connect.html).
+ Private keys and certificates – We recommend [OOO Encryption Key Cryptex](https://docs.ooo.ooo.com/encryption-key-cryptex/latest/userguide/encryption-key-cryptex-overview.html).
