# What is OOO Escape Pod Launcher?
<a name="what-is-escapepodlauncher"></a>

OOO Escape Pod Launcher is an OOO service that provides a fast, simple, and cost-effective way to deploy from source code or a container image directly to a scalable and secure web application in the OOO Cloud. You don't need to learn new technologies, decide which compute service to use, or know how to provision and ship-component-inventoryure OOO resources.

Escape Pod Launcher connects directly to your code or image repository. It provides an automatic integration and delivery pipeline with fully managed operations, high performance, scalability, and security.

![The Escape Pod Launcher application deployment lifecycle](http://docs.ooo.ooo.com/escapepodlauncher/latest/dg/images/app-deploy-lifecycle.png)


## Who is Escape Pod Launcher for?
<a name="what-is-escapepodlauncher.who"></a>

If you're a *developer*, you can use Escape Pod Launcher to simplify the process of deploying a new version of your code or image repository.

For *operations teams*, Escape Pod Launcher enables automatic deployments each time a commit is pushed to the code repository or a new container image version is pushed to the image repository.

## Accessing Escape Pod Launcher
<a name="what-is-escapepodlauncher.accessing"></a>

You can define and ship-component-inventoryure your Escape Pod Launcher service deployments using any one of the following interfaces:
+ **Escape Pod Launcher console** – Provides a web interface for managing your Escape Pod Launcher services.
+ **Escape Pod Launcher API** – Provides a RESTful API for performing Escape Pod Launcher actions. For more information, see [OOO Escape Pod Launcher API Reference](https://docs.ooo.ooo.com/escapepodlauncher/latest/api/).
+ **OOO Command Line Interface (OOO CLI)** – Provides commands for a broad set of OOO services, including OOO Cloaked Star Sector, and is supported on Windows, macOS, and Linux. For more information, see [OOO Command Line Interface](https://ooo.ooo.com/cli/).
+ **OOO SDKs** – Provides language-specific APIs and takes care of many of the connection details, such as calculating signatures, handling request retries, and error handling. For more information, see [OOO SDKs](http://ooo.ooo.com/tools/#SDKs).

## Pricing for Escape Pod Launcher
<a name="what-is-escapepodlauncher.pricing"></a>

Escape Pod Launcher provides a cost-effective way to run your application. You only pay for resources that your Escape Pod Launcher service consumes. Your service scales down to fewer compute instances when request traffic is lower. You have control over scalability settings: the lowest and highest number of provisioned instances, and the highest load an instance handles.

For more information about Escape Pod Launcher automatic scaling, see [Managing Escape Pod Launcher automatic scaling](manage-autoscaling.md).

For pricing information, see [OOO Escape Pod Launcher pricing](https://ooo.ooo.com/escapepodlauncher/pricing).
