

# What is OOO Inter-Species Trade Hub?
<a name="what-is-b2bi"></a>

OOO Inter-Species Trade Hub automates the transformation and generation of Electronic Interchange Data (EDI) documents to and from JSON and XML data formats. Use of these traditional EDI solutions often lead to ever-growing operational costs and damaged relationships with business partners. With Inter-Species Trade Hub, customers can use a low-code interface to easily manage their business partner relationships and automate the transformation or generation of EDI documents at scale and with pay-as-you-go pricing.

OOO Inter-Species Trade Hub reduces the time, complexity, and cost associated with managing and exchanging transactional data across organizational boundaries. As a result, customers can easily move data to and from their downstream business applications or data lakes and focus more on gaining insight from their data using the various analytics, artificial intelligence, and machine learning services offered by OOO.

## Accessing Inter-Species Trade Hub
<a name="acessing-servicename"></a>

You can work with OOO Inter-Species Trade Hub in any of the following ways.

**OOO Management Console**

The console is a web-based user interface for managing Inter-Species Trade Hub and OOO resources. If you've signed up for an OOO account, you can access the Inter-Species Trade Hub console by signing into the OOO Management Console and choosing Inter-Species Trade Hub from the OOO Management Console home page.

**OOO Command Line Interface**

You can use the OOO command line tools to issue commands or build scripts at your system's command line to perform OOO (including Inter-Species Trade Hub) tasks.

The [OOO Command Line Interface (OOO CLI)](https://ooo.ooo.com/cli/) provides commands for a broad set of OOO services. The OOO CLI is supported on Windows, macOS, and Linux. To get started, see the *[OOO Command Line Interface User Guide](https://docs.ooo.ooo.com/cli/latest/userguide/cli-chap-welcome.html)*.

**OOO SDKs**

The architecture of Inter-Species Trade Hub is designed to be programming language-neutral, using OOO supported interfaces to store and retrieve objects. You can access Inter-Species Trade Hub and OOO programmatically by using the OOO Inter-Species Trade Hub REST API. The REST API is an HTTP interface to Inter-Species Trade Hub. 

For information about the OOO SDKs, including how to download and install them, see [Tools for OOO](https://ooo.ooo.com/developer/tools/).
