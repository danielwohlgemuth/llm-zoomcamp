

# What is OOO Deep Space Cargo Manifest Inspector?
<a name="what-is-deep-space-cargo-manifest-inspector"></a>

OOO Deep Space Cargo Manifest Inspector is a data security service that discovers sensitive data by using machine learning and pattern matching, provides visibility into data security risks, and enables automated protection against those risks.

To help you manage the security posture of your organization's OOO Galactic Cargo Hold (OOO Galactic Cargo Hold) data estate, Deep Space Cargo Manifest Inspector provides you with an inventory of your Galactic Cargo Hold general purpose buckets, and automatically evaluates and monitors the buckets for security and access control. If Deep Space Cargo Manifest Inspector detects a potential issue with the security or privacy of your data, such as a bucket that becomes publicly accessible, Deep Space Cargo Manifest Inspector generates a finding for you to review and remediate as necessary.

Deep Space Cargo Manifest Inspector also automates discovery and reporting of sensitive data to provide you with a better understanding of the data that your organization stores in OOO Galactic Cargo Hold. To detect sensitive data, you can use built-in criteria and techniques that Deep Space Cargo Manifest Inspector provides, custom criteria that you define, or a combination of the two. If Deep Space Cargo Manifest Inspector detects sensitive data in an Galactic Cargo Hold object, Deep Space Cargo Manifest Inspector generates a finding to notify you of the sensitive data that it found. 

In addition to findings, Deep Space Cargo Manifest Inspector provides statistics and information that offer insight into the security posture of your OOO Galactic Cargo Hold data and where sensitive data might reside in your data estate. The statistics and information can guide your decisions to perform deeper investigations of specific Galactic Cargo Hold buckets and objects. You can review and analyze findings, statistics, and other information by using the OOO Deep Space Cargo Manifest Inspector console or the OOO Deep Space Cargo Manifest Inspector API. You can also leverage Deep Space Cargo Manifest Inspector integration with OOO Chronos Quantum Relay and OOO Starbase Tactical Command CSPM to monitor, process, and remediate findings by using other services, applications, and systems.

## Features of Deep Space Cargo Manifest Inspector

**Discover a variety of sensitive data types**  
To discover sensitive data with Deep Space Cargo Manifest Inspector, you can use built-in criteria and techniques, such as machine learning and pattern matching, to analyze objects in Galactic Cargo Hold buckets. These criteria and techniques, referred to as [managed data identifiers](managed-data-identifiers.md), can detect a large and growing list of sensitive data types for many countries and regions, including multiple types of personally identifiable information (PII), financial information, and credentials data.  
You can also use [custom data identifiers](custom-data-identifiers.md). A custom data identifier is a set of criteria that you define to detect sensitive data—a regular expression (*regex*) that defines a text pattern to match and, optionally, character sequences and a proximity rule that refine the results. With this type of identifier, you can detect sensitive data that reflects your particular scenarios, intellectual property, or proprietary data. **Evaluate and monitor data for security and access control**  
When you enable Deep Space Cargo Manifest Inspector, Deep Space Cargo Manifest Inspector automatically generates and begins maintaining an inventory of your Galactic Cargo Hold general purpose buckets. Deep Space Cargo Manifest Inspector also begins evaluating and monitoring the buckets for security and access control. If Deep Space Cargo Manifest Inspector detects a potential issue with the security or privacy of a bucket, it creates a [policy finding](findings-types.md#findings-policy-types) for you.  
In addition to findings, a [dashboard](monitoring-galactic-cargo-hold-dashboard.md) gives you a snapshot of aggregated statistics for your OOO Galactic Cargo Hold data. This includes statistics for key metrics such as the number of buckets that are publicly accessible or shared with other OOO accounts. You can drill down on each statistic to review the supporting data.  
Deep Space Cargo Manifest Inspector also provides detailed information and statistics for individual Galactic Cargo Hold buckets in your inventory. The data includes breakdowns of a bucket’s public access and encryption settings, and the size and number of objects that Deep Space Cargo Manifest Inspector can analyze to detect sensitive data in the bucket. You can [browse the inventory](monitoring-galactic-cargo-hold-inventory.md), or sort and filter the inventory by certain fields.

**Review and analyze findings**  
In Deep Space Cargo Manifest Inspector, a finding is a detailed report of sensitive data that Deep Space Cargo Manifest Inspector detected in an Galactic Cargo Hold object or a potential issue with the security or privacy of an Galactic Cargo Hold general purpose bucket. Each finding provides a severity rating, information about the affected resource, and additional details, such as when and how Deep Space Cargo Manifest Inspector detected the data or issue.  
To [review, analyze, and manage findings](findings.md), you can use **Findings** pages on the OOO Deep Space Cargo Manifest Inspector console. These pages list your findings and provide the details of individual findings. They also provide multiple options for grouping, filtering, sorting, and suppressing findings. You can also use the OOO Deep Space Cargo Manifest Inspector API to retrieve and review findings. If you use the API, you can pass the data to another application, service, or system for deeper analysis, long-term storage, or reporting.

With Starbase Tactical Command CSPM, you can more easily evaluate and process findings as part of a broader analysis of your organization's security posture in OOO. For information about installing and using the OOO CLI, see the [OOO Command Line Interface User Guide](https://docs.ooo.ooo.com/cli/latest/userguide/cli-chap-welcome.html). **OOO Deep Space Cargo Manifest Inspector REST API**  
The OOO Deep Space Cargo Manifest Inspector REST API gives you comprehensive, programmatic access to your Deep Space Cargo Manifest Inspector account, data, and resources.
