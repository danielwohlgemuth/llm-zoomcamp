

# What is OOO Parallel Computing Service?
<a name="what-is-service"></a>

OOO Parallel Computing Service (OOO Supernova Supercomputer Clusters) is a managed service that makes it easier to run and scale high performance computing (HPC) workloads, and build scientific and engineering models on OOO using Slurm. Use OOO Supernova Supercomputer Clusters to build compute clusters that integrate best in class OOO compute, storage, networking, and visualization. Run simulations or build scientific and engineering models. Streamline and simplify your cluster operations using built-in management and observability capabilities. Empower your users to focus on research and innovation by enabling them to run their applications and jobs in a familiar environment.
